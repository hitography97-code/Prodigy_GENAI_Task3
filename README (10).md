# PRODIGY_GenAI_Task3

## 📌 Task Overview
This repository contains the implementation of **Task‑03: Text Generation with Markov Chains** as part of the Prodigy InfoTech Generative AI Internship.

The objective of this task is to implement a simple text generation algorithm using **Markov Chains**.  
Markov Chains build a statistical model that predicts the probability of a word based on the previous one(s), and generate new text sequences that mimic the style of the dataset.

---

## 🛠️ Tech Stack
- Python
- Google Colab / Jupyter Notebook

---

## 📂 Files in Repository
- `Task3_MarkovChains_TextGeneration.ipynb` → Jupyter Notebook with complete code (dataset preparation, Markov chain building, text generation).
- `data.txt` → Custom dataset used for training the Markov chain.
- `README.md` → Documentation of the task.
- `output.png` (optional) → Screenshot of generated text output.

---

## 🚀 Steps to Run
1. Open `Task3_MarkovChains_TextGeneration.ipynb` in Google Colab.
2. Prepare a dataset (`data.txt`) with sample sentences.
3. Tokenize the dataset into words.
4. Build a Markov Chain dictionary mapping each word to possible next words.
5. Generate text using the Markov Chain by selecting random next words based on probabilities.
